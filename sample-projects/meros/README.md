# 走れメロス — サンプルプロジェクト

太宰治『走れメロス』（1940年）を原作とした Scenario Studio デモプロジェクト。
原作者没後 70 年以上が経過し、日本の著作権法上パブリックドメインです。
本プロジェクトの台詞・シーン構成は Scenario Studio 動作確認用の翻案です。

## 開き方

1. `pnpm -F @scenario-studio/frontend dev` で dev サーバ起動
2. ブラウザで http://localhost:5173/
3. 「既存プロジェクトを開く」→ `sample-projects/meros/` フォルダを選択
